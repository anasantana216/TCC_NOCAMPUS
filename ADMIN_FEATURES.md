# 🎓 NoCampus - UNASP Engenheiro Coelho

## 📋 Funcionalidades Administrativas

O sistema administrativo do NoCampus oferece ferramentas completas para coordenação escolar:

### 📅 Gerenciamento de Eventos
- ✅ Criação, edição e exclusão de eventos
- ✅ Formulários com validação completa
- ✅ Categorização por tipo (acadêmico, cultural, esportivo, etc.)
- ✅ Controle de capacidade e inscrições
- ✅ Gerenciamento de status (ativo/inativo)
- ✅ Interface moderna com filtros e busca

### 📊 Sistema de Enquetes
- ✅ Criação de enquetes com opções dinâmicas
- ✅ Visualização de resultados em tempo real
- ✅ Controle de status (ativa/encerrada)
- ✅ Estatísticas detalhadas de participação
- ✅ Interface responsiva com gráficos visuais
- ✅ Edição e exclusão de enquetes

### 📢 Gestão de Avisos
- ✅ Sistema de avisos com tipos: Informativo, Aviso, Urgente
- ✅ Controle de prioridade (baixa, normal, alta)
- ✅ Direcionamento por audiência (estudantes, responsáveis, todos)
- ✅ Programação de data/hora de publicação
- ✅ Status de publicação (rascunho/publicado)
- ✅ Interface intuitiva com badges coloridos

### 🎨 Design e Experiência
- ✅ Interface moderna com gradientes e animações
- ✅ Breadcrumb para navegação intuitiva
- ✅ Formulários responsivos e acessíveis
- ✅ Feedback visual para todas as ações
- ✅ Consistência com identidade visual UNASP
- ✅ Otimização para dispositivos móveis

### 🔧 Aspectos Técnicos
- ✅ Componentes React reutilizáveis
- ✅ Gerenciamento de estado local
- ✅ Validação de formulários
- ✅ Simulação de API para demonstração
- ✅ Roteamento com React Router
- ✅ Estilização com Tailwind CSS

## 🚀 Como Acessar

1. **Login como Administrador**
   - Acesse `/login`
   - Use credenciais de administrador
   - Será redirecionado para o Dashboard Administrativo

2. **Navegação**
   - Dashboard Principal: `/admin/dashboard`
   - Gerenciar Eventos: `/admin/events`
   - Gerenciar Enquetes: `/admin/polls`
   - Gerenciar Avisos: `/admin/notices`

3. **Funcionalidades**
   - Todos os CRUDs são funcionais
   - Interface totalmente responsiva
   - Dados simulados para demonstração
